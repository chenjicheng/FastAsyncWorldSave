# Fast Async World Save

[![CurseForge Downloads](https://cf.way2muchnoise.eu/full_951499_downloads.svg)][curseforge] [![Minecraft Versions](https://cf.way2muchnoise.eu/versions/951499.svg)][curseforge] [![Download on CurseForge](https://img.shields.io/badge/Download-CurseForge-F16436?logo=curseforge&logoColor=white)][curseforge]

Fast Async World Save is a lightweight mod which handles saving of world data, player data and dimension data offthread which avoids lagspike issues during data saving to disk.

## Installation

1. Install the required mod loader.
2. Download the mod from the official CurseForge page.
3. Place the `.jar` file in your `mods` folder.

> This mod is officially distributed only through CurseForge. Downloads from other websites may be outdated, modified, or unsafe.
